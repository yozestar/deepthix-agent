Les installateurs ne sont pas signés.
Windows : un avertissement SmartScreen peut s'afficher — cliquer sur « Informations complémentaires » puis « Exécuter quand même ».
Mac : ouvrir le fichier .dmg, glisser l'application dans Applications, puis au premier lancement faire clic droit → Ouvrir et confirmer.
Mac : piloter aussi l'agent d'un autre Mac (via Tailscale) : Paramètres › MAC DISTANT, saisir son adresse (ex. mac-mini-de-ia.tail47dd5e.ts.net) puis Ouvrir — il s'ouvre dans une deuxième fenêtre, la première reste ton agent local. Raccourci : menu Connexion › Ouvrir le Mac distant (⇧⌘M). Au premier accès, approuver le code d'appairage sur l'autre Mac.
